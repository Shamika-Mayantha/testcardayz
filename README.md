# CAR DAYZ LANKA

Futuristic marketing site for **CAR DAYZ LANKA** (Facebook: [CAR DAYZ LK](https://www.facebook.com/p/CAR-DAYZ-LK-61578866334003/)) — a Sri Lankan automotive studio for color-change wraps, PPF, ceramic coating, window tint, detailing, and cabin restyles.

The Facebook page is new and does not publish a phone number or street address, so booking routes through the official page rather than invented contact details.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) if you start with `npm run dev -- --port 4321`, or the port printed in the terminal.

```bash
npm run build
npm start
```

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- shadcn/ui
- Motion animations, canvas HUD, and a one-time boot intro
